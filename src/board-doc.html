02 — JWT Filter Chain

JWT 인증 필터 체인 흐름

클라이언트의 모든 요청은 JwtAuthFilter를 통과합니다. 토큰 유효성에 따라 SecurityContext에 인증 정보가 세팅되거나 Anonymous 상태로 넘어가고, 이후 SecurityConfig의 권한 규칙이 최종 접근 허용 여부를 결정합니다.

STEP 01
HTTP 요청 수신
Client → Server
브라우저 또는 앱이 API를 호출합니다. 로그인 후에는 Axios interceptor가 자동으로 헤더를 추가합니다.
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9...
STEP 02
JwtAuthFilter
security/JwtAuthFilter.java
OncePerRequestFilter를 상속해 요청당 정확히 한 번 실행됩니다. Authorization 헤더에서 "Bearer " 접두어를 제거하고 순수 토큰 문자열을 추출합니다.
String token = resolveToken(request); // "Bearer xxxxx" → "xxxxx"
STEP 03
JwtUtil.isValid()
security/JwtUtil.java
HMAC-SHA256 서명 검증 + 만료 시간(exp) 확인을 수행합니다. 서명 불일치, 만료, 형식 오류 모두 false를 반환합니다.
✓ VALID
토큰 정상 → 이메일·역할 추출 후 STEP 04 진행
✗ INVALID
인증 세팅 없이 필터 통과 → Anonymous 상태 유지
STEP 04
UserDetailsServiceImpl
security/UserDetailsServiceImpl.java
토큰에서 추출한 이메일로 DB를 조회해 UserDetails 객체를 생성합니다. 권한은 ROLE_USER 또는 ROLE_ADMIN으로 매핑됩니다.
loadUserByUsername(email) → UserDetails (email, password, [ROLE_USER])
STEP 05
SecurityContext 저장
JwtAuthFilter.java
UsernamePasswordAuthenticationToken을 만들어 SecurityContextHolder에 저장합니다. 이후 컨트롤러에서 @AuthenticationPrincipal로 현재 유저를 꺼낼 수 있습니다.
SecurityContextHolder.getContext() .setAuthentication(auth);
STEP 06
SecurityConfig 권한 체크
config/SecurityConfig.java
URL 패턴 + HTTP 메서드 조합으로 접근 허용 여부를 최종 결정합니다. 아래 규칙이 위에서부터 순서대로 적용됩니다.
/api/auth/** → permitAll (누구나) GET /api/posts/** → permitAll (비로그인도 조회 가능) GET /api/files/** → permitAll 그 외 모든 요청 → authenticated (로그인 필수)
✓ ALLOWED
Controller 메서드 실행
✗ DENIED
401 Unauthorized / 403 Forbidden 반환
STEP 07
Controller 도달
controller/*.java
모든 검증을 통과한 요청만 Controller에 도달합니다. @AuthenticationPrincipal로 현재 로그인 유저 정보를 바로 주입받을 수 있습니다.
@GetMapping("/me") public ResponseEntity<?> getMe( @AuthenticationPrincipal UserDetails user) { return ResponseEntity.ok(user.getUsername()); }
03 — REST API Endpoints

API 엔드포인트 목록

기본 URL: http://localhost:8080  ·  JWT 표시된 엔드포인트는 Authorization 헤더 필요

METHOD URL 설명 인증
POST /api/auth/register 회원가입 · 토큰 반환 PUBLIC
POST /api/auth/login 로그인 · 토큰 반환 PUBLIC
GET /api/posts?page=0&size=10&keyword= 게시글 목록 · 페이징 · 검색 PUBLIC
GET /api/posts/{id} 게시글 상세 조회 (조회수 증가) PUBLIC
POST /api/posts 게시글 작성 JWT
PUT /api/posts/{id} 게시글 수정 (작성자 본인만) JWT
DELETE /api/posts/{id} 게시글 삭제 (작성자 본인만) JWT
GET /api/posts/{id}/comments 댓글 목록 조회 PUBLIC
POST /api/posts/{id}/comments 댓글 작성 JWT
DELETE /api/comments/{id} 댓글 삭제 (작성자 본인만) JWT
POST /api/files/upload/{postId} 파일 업로드 (multipart/form-data) JWT
GET /api/files/download/{fileId} 파일 다운로드 PUBLIC
